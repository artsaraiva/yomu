# Security policy

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/artsaraiva/yomu/security/advisories/new), not in a public issue.

Only the latest release is supported. Yomu runs on the phone and has no server of its own. Translation stays on the phone unless you point Yomu at your own server. Reports about the app, its model downloads, its connection to a server you set up (how the key is stored and sent, and the plain-http rule), or the bundled `llama.cpp` are all in scope.
