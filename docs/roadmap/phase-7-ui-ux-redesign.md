# Phase 7 — UI/UX Redesign

**Status:** Planned
**Owner:** Yomu app
**Milestone:** #17

## Goal
Give Yomu a coherent Paper Mario / paper-mache interface while preserving clarity and accessibility.

## Scope
Navigation, overlay controls, settings, history, typography, feedback states, and the paper-craft visual language. This phase covers product feel after the workflow is proven; it does not change translation correctness.

## Exit criteria
Core tasks are discoverable, states are understandable, accessibility basics hold, and the redesigned surfaces work across supported screen sizes.

## Dependencies and issue ownership
Depends on stable behavior from Phases 1, 3, 5, and 6. UI issues belong to Yomu.
