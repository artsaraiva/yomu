# Phase 8 — Hybrid Providers & Monetization

**Status:** Planned
**Owner:** Yomu product and app
**Milestone:** #18

## Goal
Define a sustainable split between local translation and optional cloud capabilities.

## Scope
Privacy and consent, local-first defaults, cloud fallback boundaries, quotas/cost controls, entitlement behavior, and transparent user-facing value. No monetization implementation is implied by this roadmap entry.

## Exit criteria
The hybrid model has validated user value, explicit privacy behavior, predictable costs, and an implementable entitlement plan.

## Dependencies and issue ownership
Depends on quality, model, reliability, and UX evidence. Product and app issues belong to Yomu; service-specific work needs its owning repository.
