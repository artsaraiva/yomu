# Phase 5 — UI & Navigation Polish

**Milestone:** #6

## Goal

Keep the app focused on reading and translation, then apply a coherent manga-inspired visual system once core behavior is stable.

## Current delivery

[PR #8](https://github.com/artsaraiva/yomu/pull/8) simplifies navigation from five tabs to three:

- Home
- History
- Settings

It removes standalone Models and Credits tabs and makes Settings the control center.

## Remaining work

- Merge and validate PR #8 on target devices.
- Later, design paper/ink surfaces, cherry-blossom accents, and a reading-oriented visual system.
- Preserve existing overlay intent: white bubble cover, black centered text, and readable wrapping.

## Status

Functional information architecture is in review. Visual polish remains deferred until engine quality and observability improve.
