# Code of conduct

Yomu's issues, pull requests and discussions are for building and using the app. Everyone taking part is expected to:

- Be respectful and patient, especially with newcomers and people writing in a second language.
- Critique code and ideas, not people.
- Keep discussion on topic.

Not accepted: harassment, insults, discriminatory jokes or language, sexual content, personal attacks, and publishing someone's private information.

Sharing or requesting pirated manga is also off limits. Use pages you own or that are freely licensed in bug reports and examples.

## Enforcement

Report abuse with GitHub's **Report content** option on the comment, issue or pull request. The maintainer moderates this repository and may edit or remove content, lock a thread, or block someone from it, depending on how serious the problem is and whether it repeats.
